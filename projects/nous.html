Nous

不学你怎么说话，学你怎么想。

现在的 AI 分身都在行为层建模：表达风格、语言习惯、偏好。这样能做出一个说话像你的分身，但它遇到没见过的事，不会像你一样做决定，因为它不理解你是怎么想问题的。Nous 建的是认知层的模型：你为什么这样决策，而不只是你做过什么决策。

角色 — 独立开发（研究 + 全栈） 状态 — MVP 验证阶段，核心假设已确认 · 在线体验 技术 — Python · Claude API · Next.js · ECharts

Problem

说话像你，不等于想得像你。

行为层系统优化的是「看起来准」：用户满意度、使用量。认知层要优化的是「真的准」：预测命中率。等分身要替你做决定的时候，这个区别就是全部。

维度行为层认知层（Nous）
建模路径
自下而上：行为数据，等它涌现
自上而下：先建认知维度，再验证
建模对象
你做了什么
你为什么这么做
验证标准
内部指标：使用量、满意度
外部指标：对新场景的预测准确率

两层不冲突，是互补的：行为层让分身说话像你，认知层让它想得像你。

How It Works

建模是一场对话，验证是一个闭环。

AI 访谈者用 15 到 25 轮自然对话，摸清九个认知维度：决策架构、注意力分配、推理风格、情绪处理、社会认知、盲区、价值序列、不确定性应对、执行层弹性。没有问卷，也没有人格测试，就是聊天。

Key Insight

准不准，是能不能进化的问题。

「准确的模型可能不存在，但一个知道自己错在哪的动态模型，可以一直进化。」

— 这个项目的核心判断

所以重心不放在一次建准，放在验证闭环上：预测、作答、打分、修正。行为预测准确率从首测 49% 迭代到 71%（确定性打分，比随机基线高 46 个百分点），其中推理预测一档到了 90%。模型理解准确率经过一轮直接评判，从 85% 到 99%。

Contradiction Detection

矛盾是最诚实的数据。

自我报告靠不住，人对自己的描述常常是理想化的。Nous 把「你说你是谁」和「你实际怎么做」分成两轨记录，两边冲突的地方就是客观的盲区证据，不用再依赖自评。

声明轨

你说你是谁。

访谈和对话里你对自己的描述：原则、偏好、自认为的决策方式。

行为轨

你实际怎么做。

真实决策和行为的记录。两轨冲突的地方，就是模型最该追问的地方。目前已经检出 20 处矛盾。

Passive Collection

你正常工作，模型自动变准。

后台采集器从日常 AI 会话中抽取认知信号。本地关键词先做预过滤，纯技术会话直接跳过，不消耗 API 调用；有信号的会话才做抽取。用户不需要专门「喂」模型，用得越多它越准。目前累计 101 个信号、20 处矛盾。

现状MVP 的核心假设验证过了：认知模型可以靠迭代修正闭环持续提升预测准确率。下一步是把验证样本做大，再把矛盾检出变成用户能用的盲区提醒。
