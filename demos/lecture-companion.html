Why it exists

疑问真实存在,提问行为没有发生

头部备考机构的 AI 答疑能力已经可用,但公开信息显示近半学员仍依赖线下教师答疑——瓶颈不在模型能力,在输入成本:组织语言描述「我哪里没懂」这个动作,恰好发生在认知负荷最高的时刻。把输入成本压到一次点击,是整个产品的原点假设。

差异化坐标

四项同时满足者,调研范围内无

实时(课中而非课后)× 零输入(点击而非提问)× 跨内容源(线下课/网课/B 站/录播)× 私人身份(数据归学习者,不归机构)。竞品分别占其中一到三项。

形态之争

工作台,不是悬浮字幕

悬浮字幕赢在普适,但从「没懂」到「问出去」要四步切换。工作台把这个动作压到一次点击。赌注是主动交互率高于被动覆盖面——自用数据支持:41 次标记 92% 是纯点击*。

自用验证

唯一用户 = 设计者本人

n=1 不做统计结论,做的是最快的假设证伪:三个核心设计被自己的真实行为推翻过(见页尾)。统计验证有明确的实验设计与终止阈值,不假装已完成。

Product loop

课中捕捉 → 课后沉淀 → 复习消费

课中:零输入捕捉困惑实时链路,延迟即产品

转写逐句滚出;没懂点一下,系统抓当前句 + 前 5 分钟上下文 + 标记瞬间屏幕快照(老师的 PPT/板书),快模型 2 秒内给 200 字救场解释。可追问、可撤销。课程讲义上传后自动抽术语喂给 ASR 热词与解释提示词,纠正「凸/convex」类专业词误识别。

零输入标记双向断线缓冲(5 分钟)跨连接时间轴归一多模态快照ASR 热词

课后:自动沉淀资产异步链路,换更强模型档

下课自动触发:结构化课程总结(知识框架 + 薄弱区,带时间戳出处)、「别错过」事项提取(考试/作业/口头承诺 → 可订阅 ICS 日历)、跨课检索索引构建。课中的每个标记升级为可深挖的复习卡片。

定制总结事项提取 + 日历跨课 RAG 索引深挖(大白话 + 手绘示意图)

复习:五种方式 + 导引北极星在这里结账

复习页以「复习方式」而非「数据类别」组织:搭框架 / 整理没懂 / 梳理课件 / 过习题 / 回顾重点,各带完成态;导引卡按规则串成当日路线。多模态检索让扫描版讲义可检索、可按页引用、可图文对照讲解。

五方式动线复习导引北极星:被复习的标记数服务端埋点直写
Decisions, with receipts

四个关键决策,每个都有数据或代码作据

Agent 化:先立判据,再做实验,用数据否决

先定判定标准防止事后挪门柱:用户等得起几十秒延迟、且步骤写不死,两条同时满足才 agent 化。唯一合格候选(课后深挖)做最小实验:仅改 2–3 轮迭代检索,其余不动。

维度结果测量方式
延迟1.8×客观计时
token 成本1.3×用量账本
质量增量≈ 0盲评 A/B 并排
判定:全线不上 agent · 开关永久关 · 实验代码留库作负结果样本
副产品比主结论值钱:盲评发现两版「都不好懂」——瓶颈在解释的受众校准,不在检索深度。可读性改造随即立项,优先级排到全部检索工作之前。

防幻觉:页码永远不从模型嘴里出来

检索命中哪页,由代码结构化返回给前端渲染;模型只负责讲解,页码在它的输出通道之外。「错了会被立刻抓住的字段,不该来自概率分布。」

层做法
检索层页码 / 出处结构化返回,禁模型生成
阈值层0.21 — 用 376 个无关对实测校准,0.20 离无关上界仅 0.004,故不取
质检层二阶坑:质检员看不到图,曾把正确的页指涉误判为编造——修在给质检提示词补上图的存在
沉淀惯例:代码管结构,模型管内容

多模态检索:三期分险,不一步到位

扫描版讲义无文字层,文本检索对它失明。三期各只引入一个不可逆变量:一期页图入库 + 页码出处(检索门默认关,先跑热管道);二期按生产形态校准阈值后放量;三期命中页图送视觉模型,深挖输出图文对照。每期留止血开关,免回滚。

两天三期全部合并 · 零回滚 · 扫描讲义从死文件变成可检索资产
「一步到位」会让数据管道、阈值、展示三层的错搅在一起无法归因;分期不是慢,是让每层的错在它自己那期暴露。

北极星:被复习的标记数,不是标记数

每小时标记数只度量前半段(课中输入);产品承诺的闭环是「没懂的最终懂了」,发生在课后。北极星定为被复习的标记数(标记被深挖 / 自测 / 展开计一次),同时约束输入 × 消费两半。

候选指标否决理由
使用时长转写工具的指标;时长与「懂没懂」零相关
标记总数只算输入,复习为零它照样涨
被复习的标记数✓ 任何一半为零,指标即为零
定完一算,当时转化率为 0——「当前值为 0,这就是问题本身」写进复盘,复习闭环激活随即提为全队最高优先级;埋点由服务端在深挖/表态时直写,不依赖前端。
Unit economics

把自己产品的账算到分位

实时听觉通道既是护城河也是成本——按流过音频计费的 ASR 决定了实时形态无法免费规模化,这与「用得越多边际越低」的常规 SaaS 相反,也反向解释了为什么多数竞品选择零边际成本的课后资料侧。

ASR 转写 4.5 元/小时 · 约 85%
LLM ≈15%
单节 2 小时课(2 倍速实听)成本约 5.5 元,其中 LLM 全链路(解释+总结+检索)约 1 元
倍速听课按流过音频计费 → 成本随倍速线性下降,重度用户自带折扣
降档杠杆已探明:低一档 ASR 单价 1 元/小时,质量/热词/时间戳三项验证通过即可让 C 端订阅账成立
How it was built

1 名产品决策者 + 3 个并行 AI 编程代理

代理写码;任务边界、事实源、验收标准、事故裁定是人的工作。峰值单日合并 7 个功能分支,全程 433 条自动化测试门禁 + 集成 review + 高位端口真实自验。

集成主管(人 + 主会话)写任务 · review 每个分支 diff · 合并部署 · 事故裁定
Agent A深挖 / 总结 / RAG 检索 / agentic 实验——LLM 链路
Agent B材料管线 / visual RAG / 限额韧性 / ICS——数据与集成
Agent C复习页改版 / 导引 / 导航规范——体验层
最贵的一课:任务经直发消息与共享交接文件双源分配,一次不同步导致代理整批重复劳动。修的是协议不是代码——确立交接文件为唯一事实源,直发消息仅作提醒;此后零撞车。多 agent 系统的失效几乎都不在个体执行,在信息同步协议——这恰好是 AI 时代产品经理的核心工位。
